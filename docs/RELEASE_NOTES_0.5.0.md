**Pre-release / playtest build. Online play is still in testing.**

JStarsReborn 0.5.0 is the 0.4.0 Windows port plus the first online work. Offline play is unchanged from 0.4.0.

### Online (experimental, off by default)
- Turn on in the launcher: **Settings > "Online test features (experimental)"**.
- What works: Online Battle menus open; **Friendly Match > Create a Room** hosts a room; other PCs running 0.5.0 can see it under *Search for a Room*.
- What does **not** work yet: **joining a room**, so a match between two players cannot start; Rank Match and Quick Match. Unfinished functions make the game show "A communication error has occurred" and return to the menu.
- Rooms are currently found on the same local network only. The goal is direct **peer-to-peer play over the internet**; that is the next step.
- Nothing contacts PlayStation Network; no account is used. Windows may ask to allow JStarsReborn on private networks.

### Also new
- Launcher: online on/off setting; warning when an older launcher is still open.
- Runtime fixes and 300+ host self-tests (sockets, sign-in, Matching2/Signaling, room directory).
